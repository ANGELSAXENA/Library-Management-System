# Library Management System

## About the Project
This is a DBMS mini project developed using MySQL. It manages student records, book information and book issue details.

## Technologies Used
- MySQL 8.0
- MySQL Workbench 8.0
- SQL

## Database Name
`LibraryDB`

## Database Tables
1. **Students** – Stores student information.
2. **Books** – Stores book details and availability.
3. **Book_Issue** – Maintains book issue and return records.

## Features
- Student record management.
- Book record management.
- Check available books.
- View books issued to students.
- Retrieve information using SQL JOIN queries.

## Project Records
- 5 Students
- 10 Books
- 5 Book Issue Records

## How to Run
1. Install MySQL Server and MySQL Workbench.
2. Open the provided SQL file in MySQL Workbench.
3. Execute the SQL script.
4. Run the SELECT queries to view database records.
